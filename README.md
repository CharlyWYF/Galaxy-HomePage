# 查理の星空

CHARLY 的 Three.js 交互主页。每颗小行星代表一个站点、工具或旧资料入口。

## 操作

- 左键拖动平移，右键拖动旋转，滚轮缩放。
- 悬停星球或名称查看详情；单击星球拉近镜头，靠近后底部出现独立的进入按钮。双击或点击进入按钮时，镜头飞近星球后在当前标签页打开网站；连接期间持续显示提示，可返回星图取消。系统偏好减少动态效果时使用简短静态过渡。
- 飞船以平滑的非线性缓动跟随视角中心，适用于拖动、键盘平移、筛选、查看详情和归位；近景逐渐缩小至 30%。关闭详情不会单独触发返航。
- 右侧按钮缩放或恢复初始视角。
- 搜索名称、域名，或按信号、工具、记忆筛选。切换分类时会收起详情，并根据该分类的星球分布和屏幕比例自动取景，完整展示各颗星球。
- 方向键平移，+/- 缩放，Home 归位，/ 聚焦搜索，Escape 关闭详情。
- 触屏双击放大，不触发跳转；单击会短暂等待双击判定。支持单指平移、双指捏合缩放、扭转旋转、同向滑动调整方位和俯仰。轻点星球或名称查看并靠近，信息卡片保持展开；轻点空白或关闭按钮收起。手势操作会收起卡片，双指操作结束不会误触进入，跳转通过独立进入按钮确认；动画尊重系统减少动态效果偏好。

## 本地运行与部署

纯静态站点，无需安装依赖或构建。使用任意静态 HTTP 服务，例如在仓库目录运行 `python -m http.server 8000`，访问 http://localhost:8000 。ES modules 不能通过直接双击 HTML 加载。

根目录可直接部署至静态托管服务；保留原有部署方式即可。Three.js 已存放于 vendor，不依赖外部 CDN 或字体服务。网址使用本地 Oxanium 字体，突出航天仪表风格。

## 字号与镜头缩放

界面文字使用较大的基础字号；桌面端星球名称为 16px，窄屏为 14px。星图内的名称、域名和星区文字按镜头深度的 0.55 次幂缓和放大，范围为基础字号的 0.72–1.9 倍；默认远景约为 13px，越远越淡，最低不透明度为 45%。悬停或选中的名称保持清晰。固定的搜索、筛选和详情面板不随镜头缩放。相关参数位于 galaxy.js 的 labelMetrics 和 galaxy.css 的标签规则中。

## 维护

首页为 index.html、galaxy.css、galaxy.js；飞船模型由 spacecraft.js 中的轻量几何体生成。星球名称、链接、坐标、颜色和描述集中在 galaxy.js 顶部的 nodes 数组。更改脚本或样式后，同步更新 index.html 中的资源版本号以避免旧缓存。

原有 docs、cal、downloads、flv 等路径继续保留。历史外部服务可能已经停用，链接展示不代表服务存活状态。
