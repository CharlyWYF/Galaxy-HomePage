移动通信背题工具

🔺移动通信网络包括 ⚪蜂窝移动通信系统、 ⚪无绳电话系统、 ⚪无线寻呼系统、 ⚪集群移动通信、 ⚪卫星移动通信系统

🔺移动通信信道是 ⚪移动用户 在各种环境中进行通信时的无线电波传播通道

🔺移动通信信道会引起接收信号在相应的 ⚪时间域、 ⚪频率域、 ⚪空间域 产生 ⚪选择性衰落，而这些衰落不但会严重恶化移动通信的 ⚪传输可靠性，还会明显降低移动通信系统的 ⚪频谱效率

🔺无线电波传播方式：⚪直射、 ⚪反射、 ⚪绕射、 ⚪散射，其中 ⚪反射、 ⚪绕射、 ⚪散射 是影响移动通信中电波传播的基本形式

🔺直射波可按 ⚪自由空间传播 来考虑

🔺自由空间中电波传播损耗（衰减）只与 ⚪工作频率 f、 ⚪传播距离 d 有关

🔺⚪传播损耗、 ⚪阴影衰落 合并在一起反映了无线信道在 ⚪大尺度 上对信号的影响，它们主要影响 ⚪无线覆盖范围；而 ⚪多径衰落 严重影响到 ⚪信号传播质量，并且不可避免，只能采用 ⚪抗衰落技术 来减小影响

🔺表示衰落信号幅度特点的特征量：⚪衰落率、 ⚪电平通过率、 ⚪衰落持续时间

🔺衰落率是指 ⚪信号包络 在单位时间内以 ⚪正斜率 通过 ⚪中值电平 的次数

🔺衰落率与 ⚪发射频率、 ⚪移动台的行进速度、方向 及 ⚪多径传播的路径数

🔺移动通信信道是 ⚪色散信道，信号在 ⚪时域、 ⚪频域、 ⚪空间（角度） 上都产生 ⚪色散：

🔺1. ⚪多径效应 在 ⚪时域 上引起信号的 ⚪时延扩展，用 ⚪功率时延分布 描述

🔺2. ⚪多普勒效应 在 ⚪频域 上引起 ⚪频谱扩展，用 ⚪多普勒功率密度谱 描述

🔺3. ⚪散射效应 会引起 ⚪角度扩展，用 ⚪功率角度谱 描述

🔺⚪平坦衰落信道 只有 ⚪一个 ⚪可分辨径（包括多个 ⚪不可分辨径），而 ⚪频率选择性信道 ���由多个具有不同时延的 ⚪平坦衰落信道 组合而成

🔺瑞利衰落信道的统计模型由 ⚪Clarke 建立

🔺分集接收的类型包括 ⚪宏分集 和 ⚪微分集

🔺最大比合并是一种 ⚪最佳的分集合并方式

🔺时间分集是指 ⚪超过信道相关时间的时间间隔重复发送信号

🔺衰落率与 ⚪发射频率、 ⚪移动台的行进速度、方向、 ⚪多径传播的路径数 有关

🔺移动通信信道是 ⚪色散信道，信号在 ⚪时域、 ⚪频域、 ⚪空间（角度） 上都产生 ⚪色散

🔺多径效应在 ⚪时域 上引起信号的 ⚪时延扩展，用 ⚪功率时延分布 描述

🔺多普勒效应在 ⚪频域 上引起 ⚪频谱扩展，用 ⚪多普勒功率密度谱 描述

🔺散射效应会引起 ⚪角度扩展，用 ⚪功率角度谱 描述

🔺平坦衰落信道只有 ⚪一个 ⚪可分辨径（包括多个 ⚪不可分辨径），而 ⚪频率选择性信道是由多个具有不同时延的 ⚪平坦衰落信道组合而成

🔺对于频率选择性衰落信道，最常用的仿真模型是 ⚪抽头延时线模型

🔺Clarke建立了一个描述 ⚪平坦小尺度衰落 的统计模型，该模型适用于描述 ⚪瑞利衰落信道

🔺Jakes仿真模型模拟的是在均匀散射环境中 ⚪非频率选择性衰落 信道的非低通包络

🔺移动通信网由 ⚪空中网络 和 ⚪地面网络 两部分组成

🔺在移动通信网内，无线电干扰一般分为 ⚪同频干扰、 ⚪邻道干扰、 ⚪互调干扰、 ⚪阻塞干扰、 ⚪近端对远端的干扰

🔺⚪空间分集 是利用相距足够远的不同天线产生的电场相互独立这一特性而构成的分集技术，也称 ⚪天线分集

🔺⚪时间分集 是指超过信道相关时间的时间间隔重复发送信号

🔺⚪GSM移动通信系统 使用 ⚪跳频 获得频率分集

🔺⚪极化分集 可以看作 ⚪空间分集 的一种特殊情况，仅仅是利用了不同 ⚪极化波 具有不相关的衰落特性而缩短了天线间的距离而已

🔺⚪角度分集 在接收端使用 ⚪方向性天线，使他们指向不同的 ⚪波达方向，则每个方向性天线接收到的多径信号是 ⚪不相关的

🔺⚪空时编码STC 是 ⚪信道编码设计 和 ⚪发送分集 的结合

🔺主流多址接入技术包括：⚪FDMA、 ⚪TDMA、 ⚪CDMA、 ⚪SDMA、 ⚪OFDMA
