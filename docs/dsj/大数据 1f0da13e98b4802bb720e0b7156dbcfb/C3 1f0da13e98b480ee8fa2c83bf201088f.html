数据管理技术的发展历程

文件系统阶段面向某个应用或某个程序
数据库系统阶段面向整个企业或整个应用的
数据仓库阶段面向主题的、集成的、非易失的、随时间而变化的 数据集合
分布式系统阶段建立在网络之上的软件系统

数据库的数据模型

  • 层次模型（树状结构)
  • 网状模型（有向图）
  • 关系模型（表格：二维表）
根本区别：数据之间联系的表示方法不同

具体优缺点 见PPT3.2

ACID特性—关系数据库

  • Atomicity 原子性
  • Consistency 一致性
  • Isolation 隔离性
  • Durability 持久性

数据仓库的特性

  • 面向主题的
  • 集成的
  • 数据不可更新的
  • 数据随时间不断变化的

CAP理论—分布式系统

  • Consistency 一致性
  • Availability 可用性
  • Partition 分区容忍性
一个分布式系统不可能同时满足三个，最多同时满足其中俩个

BASE思想—NoSQL数据库

  • Basically Available 基本可用
  • Soft state 软状态
  • Eventual consistency 最终一致性 （允许短暂的数据不一致性）
