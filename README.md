# 查理の星空

CHARLY 的 Three.js 交互主页。每颗小行星代表一个站点、工具或旧资料入口。

## 操作

- 左键拖动平移，右键拖动旋转，滚轮缩放。
- 单击星球或名称查看详情；双击在当前标签页进入对应网站。
- 右侧按钮缩放或恢复初始视角。
- 搜索名称、域名，或按信号、工具、记忆筛选。
- 方向键平移，+/- 缩放，Home 归位，/ 聚焦搜索，Escape 关闭详情。
- 触屏支持单指平移、双指缩放；动画尊重系统减少动态效果偏好。

## 本地运行与部署

纯静态站点，无需安装依赖或构建。使用任意静态 HTTP 服务，例如在仓库目录运行 `python -m http.server 8000`，访问 http://localhost:8000 。ES modules 不能通过直接双击 HTML 加载。

根目录可直接部署至静态托管服务；保留原有部署方式即可。Three.js 已存放于 vendor，不依赖外部 CDN 或字体服务。

## 维护

首页为 index.html、galaxy.css、galaxy.js。星球名称、链接、坐标、颜色和描述集中在 galaxy.js 顶部的 nodes 数组。更改脚本或样式后，同步更新 index.html 中的资源版本号以避免旧缓存。

原有 docs、cal、downloads、flv 等路径继续保留。历史外部服务可能已经停用，链接展示不代表服务存活状态。
